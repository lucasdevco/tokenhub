# 添加界面语言

语言列表由 `catalog.json` 管理。`defaultLocale` 保持为 `en`。前端选择器、语言校验和桌面端字典加载都使用这份列表。

1. 在 `catalog.json` 的 `locales` 中添加语言代码及其本地名称，例如 `"ja": "日本語"`。
2. 复制 `locales/en.json` 为 `locales/ja.json`，保留全部键，翻译各键的值。文件名必须与语言代码一致。
3. 保留 `{0}`、`{1}` 和 `%v` 等占位符，可以按目标语言的语序调整位置。
4. 在 `web` 目录运行 `pnpm i18n:check`，修复检查报告的问题。
5. 运行 `pnpm test` 和 `pnpm build`，并检查新增语言下的页面与菜单布局。

使用完整英文文案作为键，例如 `t("Request logs")`，不使用 `logs.title` 这类标识。英文词典中写 `"Request logs": "Request logs"`，中文词典中写 `"Request logs": "请求日志"`。

新增界面文案时，在英文和其他语言字典中添加相同的英文键。修改英文原文时，同步更新调用处和所有词典的键。两个场景需要不同翻译时，使用能区分语境的英文原文。

`pnpm test` 和 `pnpm build` 自动检查语言登记、缺失字典、缺失或空翻译、多余的键及占位符差异，也检查前端和桌面代码中的静态翻译键是否存在于英文词典。

运行时先查所选语言，再回退到英文。两份字典都没有的消息保留原文，以便展示外部诊断信息。检查会阻止缺失翻译进入正常构建。
